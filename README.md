# Projekt_0MS
Projekt do předmětu matematický softaware na práci s daty

V tomto projektu se zabívám spokojeností pasažéru s aerolinkami. Využívám k tomu 3 modely: Decision Tree, Random Forest a SVM.

Zdroj dat: https://www.kaggle.com/datasets/teejmahal20/airline-passenger-satisfaction?resource=download

pro spuštění je třeba stáhnout Main branch a ve složce, kde jsu všechny python scripty přes terminál spustit příkaz:
         "python main.py"

Na starším notebooku mi trval celý proces necelých 8 minut, tudž mějte prosím také trpělivost.
Grafy se uloží do své vlastní podsložky ve stejné složce, ve které jste spouštěli skript.
